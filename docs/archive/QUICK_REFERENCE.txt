│ API ENDPOINTS                                                                │
└──────────────────────────────────────────────────────────────────────────────┘

Authentication
  POST   /api/token/                  ← Get JWT token
  POST   /api/token/refresh/          ← Refresh token

Resources
  GET    /api/users/                  ← List users (admin)
  POST   /api/users/                  ← Create user (admin)
  
  GET    /api/services/               ← List services
  POST   /api/services/               ← Create service (admin)
  
  GET    /api/applications/           ← List applications
  POST   /api/applications/           ← Create application
  POST   /api/applications/{id}/update_status/ ← Update status (admin)
  
  GET    /api/documents/              ← List documents
  POST   /api/documents/              ← Upload document
  
  GET    /api/final_documents/        ← List final documents
  POST   /api/final_documents/        ← Upload final (admin)

Admin
  GET    /admin/                      ← Django admin panel

│ QUICK START                                                                  │
└──────────────────────────────────────────────────────────────────────────────┘

1️⃣  Set Admin Password
    $ cd sewa_portal
    $ python manage.py changepassword admin

2️⃣  Start Server (Option A - Easy)
    $ cd /home/rohan/Desktop/projects/CGJBCSC
    $ ./start_server.sh

    Start Server (Option B - Manual)
    $ source sys/bin/activate
    $ cd sewa_portal
    $ python manage.py runserver 0.0.0.0:8000

3️⃣  Access Application
    🌐 API Root:    http://localhost:8000/api/
    🔐 Admin:       http://localhost:8000/admin/
    📚 Docs:        See API_TESTING_GUIDE.md

4️⃣  Test API
    # Get token
    $ curl -X POST http://localhost:8000/api/token/ \
      -H "Content-Type: application/json" \
      -d '{"username": "admin", "password": "your_password"}'
    
    # List services
    $ curl http://localhost:8000/api/services/ \
      -H "Authorization: Bearer YOUR_TOKEN"
